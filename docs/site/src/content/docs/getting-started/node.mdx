示例：

- Mock 循环：[`examples/node-cli`](https://github.com/bugkiwi/OtterVoice/tree/main/examples/node-cli)
- 复合后端：[`examples/node-openrouter`](https://github.com/bugkiwi/OtterVoice/tree/main/examples/node-openrouter)

```bash
bun run examples/node-openrouter/index.ts
# 可选：export OPENROUTER_API_KEY=...
```

```ts
import { createVoiceSession } from '@ottervoice/core';
import { createNodeRuntime } from '@ottervoice/runtime-node';
import { createOpenRouterAudioLLM } from '@ottervoice/provider-openrouter';

const runtime = createNodeRuntime();
const session = createVoiceSession({
  mode: 'half_duplex',
  runtime,
  providers: {
    audioLlm: createOpenRouterAudioLLM({
      apiKey: process.env.OPENROUTER_API_KEY!,
      model: 'openai/gpt-audio-mini',
      voice: 'alloy',
    }),
  },
});

await session.start();
```

服务端也可以用 `createOpenRouterLLM()`、ASR 与 `createOpenRouterTTS()`
实现一个复合 `AudioLLMProvider`；[`examples/node-openrouter`](https://github.com/bugkiwi/OtterVoice/tree/main/examples/node-openrouter)
展示了这个边界。浏览器 / App 必须走 [Token Broker](/docs/getting-started/token-broker/)。
